# SSH Server Connector
SSH 서버 연결 및 GPU 상태 모니터링을 위한 GUI 애플리케이션입니다.

## 기능
- SSH 서버 연결 관리
- GPU 상태 모니터링
- VS Code 원격 연결  
- 사용자 접속 현황 확인

## 설치 방법

1. 저장소 클론
```bash
git clone https://github.com/hehebubu/SSH_DASH.git
```

2. 의존성 설치
```bash
# 프로젝트 디렉토리로 이동
cd SSH_DASH

# requirements.txt로부터 필요한 패키지 설치
pip install -r requirements.txt
```

3. 실행
```bash
python new.py
```
